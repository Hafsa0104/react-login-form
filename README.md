## Running the Project

Clone the repository:

```bash
git clone https://github.com/Hafsa0104/react-login-form.git
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm start
```

Open:

```
http://localhost:3000
```

Run tests:

```bash
npm test
```
